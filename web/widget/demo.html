FEN status widget — demo (Flow 2)

Shows gfen:validationStatus for an annotation, resolved live from the RDF store via the Status API (GET /api/v1/status/{id}). Click a badge for decision details (method, PID, ledger anchor).

Embedded widgets

How to embed

<script src="fen-status-widget.js"></script>
<fen-status annotation-id="annotation_a1" api-base="http://localhost:8082"></fen-status>

Attributes: annotation-id (required), api-base (default http://localhost:8082), theme (dark|light). Read-only widget — it never writes to the graph (ADR-001).
