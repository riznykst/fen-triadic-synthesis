Architecture

Python microservices over Kafka + RDF

FastAPI · Pydantic v2 · RDFLib
  • fen-bridge — outbound consumer (Kafka → mock DAO) and webhook receiver (DAO decisions → Kafka).
  • validation-consumer — applies community decisions to the RDF store via SPARQL UPDATE (hash-only anchoring, ADR-001).
  • status-api — read-only API: validation status, SSE live events, RDF / RO-Crate export.
  • mock-fen-api — demo DAO: community / quadratic voting, LLM reviewer (decision-support only, ADR-004), agentic Scaffold.
  • web/ — zero-build UI: classic DAO portal, Triadic view, embeddable <fen-status> widget.
  • Docs — ADR-001..006, whitepaper PDF, ontology & SHACL shapes in docs/.
